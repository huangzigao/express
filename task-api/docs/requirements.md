# Task API 需求说明

## 项目范围

`task-api` 是一个支持用户认证、个人任务管理和任务分类的 REST API 服务。

## 用户

- 用户可以注册。
- 用户可以登录。
- 用户登录后通过 JWT 访问受保护接口。
- 用户只能访问自己的任务和分类。

## 任务

- 创建任务。
- 查询当前用户的任务列表。
- 查询任务详情。
- 修改任务。
- 删除任务。
- 支持状态、优先级、截止时间和分类。

## 分类

- 创建分类。
- 查询当前用户的分类。
- 修改分类。
- 删除分类。
- 任务可以关联一个分类。

## 查询能力

- 支持分页。
- 按状态筛选。
- 按优先级筛选。
- 按分类筛选。
- 按截止时间筛选。
- 按创建时间或截止时间排序。

## 非功能要求

- 所有正式业务数据持久化到 MySQL。
- 所有接口返回统一格式。
- 所有外部输入经过参数校验。
- 核心接口具备自动化测试。
- 错误日志不能记录密码和 JWT。

## 第一版暂不实现

- 多人协作任务。
- 团队和组织管理。
- 邮件通知。
- 文件上传。
- 第三方登录。
- 实时通信。
- 管理员后台。
- Web 前端页面。
