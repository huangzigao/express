# 技术选型说明

## 运行环境

- Node.js
- npm

## 核心依赖

- Express：提供 HTTP 服务和路由能力。
- Prisma：提供数据库访问、类型安全和迁移能力。
- MySQL：保存用户、任务和分类等关系型数据。
- Zod：校验请求参数和环境变量。
- `jsonwebtoken`：生成和校验 JWT。
- `bcrypt`：安全处理密码哈希。

## 开发依赖

- Jest：测试运行器。
- Supertest：HTTP 接口测试。
- Nodemon：开发环境自动重启。
- ESLint：代码检查。
- Prettier：代码格式化。

## 公共能力

- Pino：输出结构化请求和错误日志。
- Helmet：设置基础安全响应头。
- CORS：配置跨域访问策略。

## 选择原因

项目包含用户、任务和分类之间的关系，需要数据库事务、外键和唯一约束，因此选择 MySQL。

项目需要保持路由、控制器、业务服务和数据访问职责清晰，因此后续按分层结构开发。

Prisma 负责数据库模型、迁移和数据访问；Zod 负责边界输入校验，避免校验逻辑散落在业务代码中。

JWT 用于无状态身份认证，bcrypt 用于密码哈希，服务端不保存明文密码。

## 第一阶段约束

- 今天只确定技术方案，不安装依赖。
- 业务数据不使用内存数组作为最终存储。
- 数据库表结构在明确字段和删除策略后再创建。
- 依赖版本在项目初始化时统一确认并记录。
